# Banco de temas — Histórias Bíblicas

Lista de ideias prontas para colar no campo "tema do vídeo" da WebUI ou da
API. Organizadas por bloco para facilitar um calendário de postagens
variado (não postar só Antigo Testamento em sequência, por exemplo).

Dica: para roteiros mais longos (Shorts de 60-90s), peça 2-3 parágrafos; para
vídeos mais curtos (30-45s), 1 parágrafo.

## Formatos alternativos (para variar o canal)

- "Curiosidades bíblicas": 60 segundos sobre um detalhe pouco conhecido de
  uma história já contada antes.
- "O que a Bíblia diz sobre X" (perdão, medo, coragem, inveja) contado
  através de uma história específica.
- Comparação entre duas figuras bíblicas (ex.: Davi x Saul, Caim x Abel).
